# FUSE Vercel Deployment

Static Vercel-ready 3D viewer generated from the FreeCAD XHTML export.

## Deploy on Vercel

No build command or framework is required.

1. Push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Select **Other** / no framework preset.
4. Leave Build Command and Output Directory empty.
5. Deploy.

The viewer uses X3DOM 1.8.3 over HTTPS.
